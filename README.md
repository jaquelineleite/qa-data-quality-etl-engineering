# QA Data Quality & ETL Engineering

Projeto de Quality Engineering focado em validação de dados, pipelines ETL/ELT e Data Quality.

## Objetivo

Simular uma arquitetura de dados de transações financeiras e implementar uma estratégia completa de testes para validar:

- ETL/ELT
- Source-to-Target Testing
- Data Reconciliation
- Data Quality
- Regras de transformação
- Integridade referencial
- Grandes volumes de dados
- CSV, JSON, TXT e Excel
- SQL avançado
- PostgreSQL
- SAS
- Automação de testes
- CI/CD
- Shift Left Quality

## Arquitetura

Source Data
    ↓
Staging
    ↓
ETL
    ↓
Data Warehouse
    ↓
Data Quality Tests
    ↓
Evidence & Reports
